# Contributing

Use Node 20.9+. Install from the root and web lockfiles. Run `npm test`, the production web build, and browser regression tests before submitting changes. See VERIFY.md for commands and evidence scope.

Do not commit credentials, node_modules, build output, or fabricated verification reports. Keep local models, RPC responses, and transactions clearly separated. Changes to policy semantics require updates to the shared specification, reference-contract tests, and documentation.

Deployments or transactions require the maintainer’s explicit approval. Do not use historical notes in docs/archive as current contract or security specifications.
